XTERM CORE 2 BUILD CONFIGURATION

Source variants:
- Debian Bookworm xterm 379-1 (upstream patch level 379)
- Debian sid xterm 412-1 (upstream patch level 412), built on Debian 12

Compiler:
- -O2 -march=core2 -mtune=core2

Compile-time feature:
- OPT_SCROLL_LOCK=1 is forced through DEB_CPPFLAGS_MAINT_APPEND.
- ptyx.h also defaults OPT_SCROLL_LOCK to 1 when no override is defined.
- The existing util.c implementation of autoScrollLock is upstream code. No custom viewport patch is carried.

Relevant upstream path:
- util.c: xtermScroll() contains the OPT_SCROLL_LOCK branch.
- ptyx.h: TScreen scroll-lock fields are present under OPT_SCROLL_LOCK.
- xterm.h: scroll-lock actions and handlers are declared under OPT_SCROLL_LOCK.

Runtime:
- scrollTtyOutput must be false (-si).
- autoScrollLock must be true.
- Example: xterm -si -xrm 'XTerm*autoScrollLock: true'

Lean build options:
- --without-xinerama: no Xinerama extension support or library linkage.
- --disable-toolbar: omit xterm's optional pulldown toolbar.
- xterm has no native tabbed-window UI. VT horizontal tab-stop handling remains part of terminal emulation and is not disabled.

This repository builds the two Debian packages; it does not modify the upstream scrollback algorithm.
